## 0. 謎の答え（ネタバレ・全体の芯）

**世界から言葉と刻が失われたのは、事故ではない。最初の探究者アルマが、世界を守るために自分の手で止めたから。**

**観測者が取り戻すのは人ではなく、人が遺した光（星空）。人々は戻らず、観測者は最後まで一人で旅をする。** 灯した星は、いつか来る次の観測者の夜空になる。観測者どうしは決して出会わず、品と文書だけを次へ遺していく（孤独のリレー）。

| 用語 | 意味 |
| --- | --- |
| 星脈（せいみゃく） | 灯から立ちのぼり、夜空をめぐる光の脈。人が知ろうとして費やした「刻」と、それを綴った「言葉」が昇っていき、夜空に星として灯る。星はどれも誰かの一夜。 |
| 星詠みの学院 | アルマの小屋の机から始まり、星脈を守ってきた学院。 |
| アルマ | この世界で最初の探究者で、学院を開いた人。机の灯は、アルマの前に誰かが残していったもの。「先人」はすべてこの一人につながる。最後には自分の刻と名を星冠の鈴に溶かし、古代の魔法陣（プロローグの陣）を遺した。アルマもまた、かつて名も知らぬ誰かの陣に呼ばれた観測者だった。 |
| 言葉の溶解 | 人が言葉を読まずに眺め、軽く消費するようになった。根を張れない言葉は溶けて星脈へ流れ込み、中身のない光で脈を濁らせた。 |
| 刻の崩壊 | 人が時間を費やさず、ただ流すようになった。流されただけの刻は星にならず、世界の暦（天文盤）の歯が欠けていった。 |
| 大沈黙（星脈の沈黙） | 濁って薄まった星脈は焼き切れる寸前だった。アルマは〈天球の調律器〉を逆に回して星脈を止め（＝刻が失われる）、まだ重さを持つ言葉を一冊の原典に回収して封じた（＝言葉が失われる）。言葉と刻は**失われたのではなく、預けられた**。刻と言葉を失った人々は、凍った星脈に溶けて、瞬きをやめた星になった。 |
| 星になった人々 | 夜空の星は、どれもかつて学んだ人の光。観測者が詠唱で灯すのは、この人たちの光。星は瞬きを取り戻しても、人は戻らない。夜空がにぎやかになるほど、地上にいるのは自分ひとりだと分かる。 |
| 凍れる刻 | 深く集中して費やされた一時間だけは、沈黙のなかでも凍って結晶になり、大回廊に残った。 |
| 詠唱 | 沈黙の後、魔導炉の錬金術師たちが編んだ再点火の儀式。集中して費やした刻が炉で星屑に変わり、星脈へ還って凍った星をひとつ灯す。MP はこの刻の量にあたる。配合表の最後の欄は「後から来る者の刻」のために空けてある。錬金術師たちは自分の刻を炉に注ぎ尽くし、最初に灯り直した星になった。 |
| 観測者（ユーザー） | アルマの遺した陣に呼ばれた後継者で、地上に残るただ一人。STAGE 1→6 の道は、世界が失ったものを、失った順にたどり直して拾い直す道になっている。図鑑の品は、先にこの道を歩いた者たちの遺品。 |
| 流れ星 | 詠唱に応えて星脈から零れる、刻の欠片（宝箱の中身）。 |
| 再創生の四器（SS） | アルマの封印を解き、星空に先人の光を戻すための器具。止めた調律器・封じた原典・最後の星を、観測者の刻（星屑の原石）で作り直したもの。人を蘇らせる力はない。 |
| 周天 | 一度灯しただけの星脈は細く、すぐまた弱まる。巡るたびに脈は太くなる。周を重ねると、前の周の自分が「先人」になる（影の章で鈴に刻まれた自分の名を見つける）。旅の道連れは、過去の自分の背中だけ。 |
| 星天の塔 | 果てのない塔。旅に終わりはなく、最後まで一人で昇り続ける。 |

### 時系列

1. **黄金期**（STAGE 1 始まりの書斎）: アルマが机で最初の一行を覚える → 星脈が生まれる → 学院が栄える
2. **言葉の溶解**（STAGE 2 樹海の図書室）: 言葉が軽くなり、樹海の光が弱まる。アルマは残った言葉を根の迷宮に隠す
3. **刻の崩壊**（STAGE 3 星空の観測塔）: 星が増えなくなり、天文盤が軋む。アルマが調律器を持ち出す
4. **大沈黙**（STAGE 4 蒼氷の大回廊）: アルマが星脈を止め、言葉を原典に封じる。世界が凍り、人々は星になる
5. **詠唱の儀式**（STAGE 5 紅蓮の魔導炉）: 残った錬金術師たちが、落ちた星を薪に詠唱の儀式を作る。刻を注ぎ尽くして星になるが、彼らの刻だけでは足りない
6. **継承**（STAGE 6 天空の大聖堂）: アルマは鈴に溶け、陣を遺す。地上に誰もいなくなった世界で、観測者が詠唱を始める
7. **再創生**（錬成陣・周天・星天の塔）: 四器を錬成し、封じた言葉と刻を星空へ戻していく。灯した夜空は次の観測者へ渡る

### 情報の出し方（二重構造）

- **表軸（古代文書）**: 何が起きたか。4葉それぞれに一場面ずつ書き、**4葉が揃って復元したときだけ「秘された結び」が現れる**。結びは裏軸への手がかり。
- **至宝 S**: 誰が・どうやって止めたか（調律器を逆に回したのはアルマ、言葉は預けられた）。
- **神話 SS**: なぜ止めたのか、どう元に戻すのか（再創生の四器）。
- **伝承の品 B / 秘宝 A / 触媒 C**: その時代に残った物の証言。どの品も、時系列のどこかの一場面を指す。

## 1. データ構造

既存の型（`src/lib/items.ts`）でほぼ足りている。依頼にあったフィールドとの対応は次のとおり。

| 依頼のフィールド | 既存の型 |
| --- | --- |
| id / name / rarity | 同名 |
| category | `type: "触媒" \| "伝承" \| "装置"` ＋ `kind` |
| flavor_text | `flavorText` |
| effect | `effect`（`blessingLabel` で自動生成） |
| 錬成レシピ（target_ss_id, required_stone_count, required_materials） | `RelicItem.recipe: { ore: number; relics: string[] }`（神話遺物の側に持たせる） |

古代文書だけ型を変える。今は 4 葉とも定型文で、本文は `memory` にまとめて入っているため、断片を集めながら読み進められない。

```ts
/** 古代文書: 各ステージに1冊。4葉それぞれに一場面ずつ記され、揃うと秘された結びが現れる */
export type AncientDocument = {
  id: string;
  stageId: number;
  title: string;
  /** 文書が書かれた時代（例: 黄金期） */
  era: string;
  color: string;
  /** 断片 I〜IV の本文。手に入れた葉から読める */
  fragments: [string, string, string, string];
  /** 4葉が揃って復元したときだけ現れる結び */
  coda: string;
};

// FRAGMENTS: flavorText = doc.fragments[i]
// MEMORIES:  memory = [...doc.fragments, doc.coda]（＝復元時のフルストーリー）
```

復元時のフルストーリー ＝ 断片 I〜IV ＋ 秘された結び。

### STAGE 1『灯火の誓約』— 黄金期 / 記: 学院の祖アルマ

- **I** はじめに、世界には灯がひとつしか残っていなかった。誰がともしたとも知れない小屋の机の上、問いを抱いた者の前にだけともる、小さな光だった。
- **II** 灯の下で覚えた一行は、灯から細く立ちのぼり、空をめぐる光の脈になった。人はそれを星脈と呼んだ。知ろうとして費やした刻と、それを綴った言葉は、星脈を昇って夜空に星を灯す。
- **III** やがて机は書斎になり、書斎は学院になった。星詠みの学院。夜ごと星は増え、空は誰かの一夜で埋め尽くされていった。言葉はまだ重く、刻はまだ濃かった。
- **IV** だから我らは誓う。灯を絶やさぬために、今宵もひとつ、まだ知らぬことを知ろうと。――学院の祖、アルマ
- **秘された結び** 追記。この誓いを守れなくなる日が来たら、灯だけは、この机に残していく。

### STAGE 2『樹海の言の葉』— 言葉の溶解 / 記: 樹海の司書

- **I** 樹海の木々は、読まれた言葉を養分にして育つ。声に出して読まれた一文は根となり、考え抜かれた一文は幹となる。
- **II** いつからか、人は言葉を読まずに眺めるようになった。速く、多く、軽く。根を張れない言葉は樹海に溢れ、葉の上で溶けて流れていった。
- **III** 溶けた言葉は星脈に流れ込み、中身のない光で脈を濁らせた。写本の妖精たちは綴る意味を失って去り、大樹の囁きは日ごとに早口になった。
- **IV** アルマは残った言葉を根の奥へ隠し、迷宮で囲った。『守れるのは、まだ重さを持つ言葉だけだ』と。――樹海の司書の記録
- **秘された結び** 迷宮の最も深い書架は空だった。そこに収めるはずの一冊を、アルマはまだ書いていなかった。

### STAGE 3『星読みの手稿』— 刻の崩壊 / 記: 観測塔の星読み

- **I** 空の星は、かつてこの地で学んだ者たちの灯である。ひとりが一夜を費やして理を解くたび、夜空にはひとつ星が増える。
- **II** 我々が数えていたのは天体ではなく、先人たちの夜の数だった。だがここ幾年か、星はほとんど増えていない。人は刻を費やさず、ただ流すようになった。
- **III** 流されただけの刻は星にならない。天文盤の歯は一枚、また一枚と欠け、世界の暦は数えられない夜を抱えたまま軋みはじめた。
- **IV** 今夜、また一つ星が瞬きをやめた。明日の星は、今日より一つ少ない。――観測塔の星読み
- **秘された結び** 最後の夜、アルマが塔に来て、調律器を持ち出していった。止めるつもりなのだと、私は気づいていた。

### STAGE 4『凍れる時の碑文』— 大沈黙 / 記: 名を削られた者

- **I** その夜、星脈は沈黙した。空の星はすべて瞬きをやめ、時計塔の針は一斉に止まった。
- **II** 刻が止まると、言葉もまた世界から抜け落ちた。名を呼べず、問いを持てなくなった人々は、凍った星脈に溶けて、瞬きをやめた星になった。これを大沈黙と呼ぶ。
- **III** けれど、すべてが失われたのではない。深く集中した者の一時間だけは、凍りついて結晶となり、この回廊に残った。大回廊の氷は、すべて誰かの一時間である。
- **IV** 費やした刻は失われない。形を変えて、いつか解かれる日を待っている。――碑文を刻んだ者の名は、削り取られている
- **秘された結び** 止めた手は震えていた。世界を壊すためではなく、壊れる前に眠らせるための手だった。

### STAGE 5『熾火の錬成録』— 詠唱の儀式 / 記: 魔導炉の錬金術師たち

- **I** 沈黙の後、我々は凍えて空から落ちた星を拾い集め、炉に焼べた。凍った世界で、刻を生み直す熱が要った。
- **II** 刻は奪っても、移しても生まれない。ひとりが集中して費やした分だけが、炉の中で星屑に変わる。我々はその手順を詠唱と名付けた。
- **III** 刻を積み、わずかに残った言葉を添え、炉の火で練る。集積が満ちれば星屑は星脈へ還り、凍った星をひとつ灯す。だが、我々の刻だけでは足りなかった。
- **IV** 配合表の最後の欄は空けておく。後から来る者の刻でしか、この儀式は完成しない。――魔導炉の錬金術師たち
- **秘された結び** 我々の刻は、もうじき尽きる。尽きた者から星脈へ還り、空に灯る。炉の番は火竜に託した。いつか誰かが来るまで、竜は我々の代わりに夢を見続ける。

### STAGE 6『星冠の聖典』— 継承 / 記: アルマ

- **I** この聖典を読む者よ。あなたが辿ってきた道は、世界が失ったものを、失った順にもう一度拾い直す道だった。
- **II** 灯の机で問いを持ち、樹海で言葉の重さを知り、星を数え、凍った刻に触れ、炉で詠唱の由来を知った。それは世界が手放していったものの順番で、私が世界に返せなかったものの順番だ。
- **III** 私もかつて、名も知らぬ誰かの遺した陣に呼ばれた一人だった。だから自分の刻と名を星冠の鈴に溶かし、陣を遺す。いつか誰かが、その陣の前で詠唱を始めるように。私たちが会うことはない。
- **IV** 観測者よ。あなたの一夜は、錬金術師たちの後に続いて、凍った空にふたたび灯る星になる。次の誰かにとって、あなたが最初の灯になる。――アルマ
- **秘された結び** けれど一度灯しただけでは、星脈はすぐにまた細くなる。巡りなさい。周天の先で、私が封じたものが待っている。見上げた空の星はどれも、あなたより先にこの道を歩いた者の光だ。あなたは一人だが、独りではない。
