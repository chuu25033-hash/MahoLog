# X（Twitter）運用方針

## 役割
- **勉強垢の輪に入り、使ってくれる人と出会う場所**。TikTok より「使い方」「作り手」「日々の記録」を見せる
- 投稿のリンクは押せるが、本文にリンクを入れると表示されにくいとされるので、**プロフィールと自分の返信**に置く
- プロフィールのリンクには `?utm_source=x` を付け、TikTok と流入を比べる

## プロフィール
- ユーザー名: `maholog` など半角英数字（TikTok とそろえる）
- 表示名: `マホログ 学びを魔力に変える勉強記録`（記号が入らなければ `マホログ` だけでも可）
- 紹介文:
```
学んだ時間が、魔力になる。
勉強時間を「詠唱」として記録し、星の世界に眠る秘術を解き明かしていく学習記録アプリ。
誰とも競わない、己の探求だけを記す書。
無料・登録不要、ブラウザですぐ始められます。
```

## 投稿のきまり
- 定期投稿は**週3本（月・水・金の21時）**＋ **自分の勉強記録を毎日**（アプリの共有画像）
- 投稿は140文字（全角）まで
- ハッシュタグは3つまで。内容で使い分ける
  - アプリの紹介・開発の話: `#個人開発` `#マホログ`
  - 勉強の記録: `#勉強垢さんと繋がりたい` `#勉強記録` `#マホログ`
- TikTok の動画は、TikTok に投稿した翌日以降に X にも載せる
- 投稿のあと10分ほど、「#勉強垢さんと繋がりたい」の投稿にいいね・返信をする

## 種類（シリーズ）
| シリーズ | 内容 | 素材 |
| --- | --- | --- |
| 紹介 | アプリの遊び方・世界観 | 予告編の静止画・動画 |
| 伝承の品 | 遺物1つと解読文 | 撮影ツールの静止画 |
| 開発ログ | 作った理由、こだわり、作り方 | スクリーンショット・音 |
| 今夜の詠唱 | 自分の勉強記録（毎日） | アプリの共有画像 |
