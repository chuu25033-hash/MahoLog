## T02 25分勉強すると、こうなる。（投稿済 11/1 日 21時、前倒し）
- 動画: `video/out/t02-chant.mp4`（28秒）。場面は `src/components/trailer/chant-short.tsx`、確認は `/trailer/chant`
- 撮影: `node capture.mjs --url http://localhost:3000/trailer/chant --out out/t02-chant.mp4`

**狙い**: タイマーと報酬の演出に絞る。冒頭の一行で何の動画かを示し、「こうなる」の答え（報酬）を6秒台に置く
**報酬はアプリの仕様どおり**: 25分で降る流れ星は1つ、魔力は +25 MP。ガチャのような抽選の演出は使わない
**音**: 効果音は数を絞って静けさを残す。曲と同じオルゴール・ピアノ・鐘の音色で、同じ F の調に合わせる。曲は「ボンッ」で最初の和音（Fmaj7）が鳴るよう始める

| 秒 | 場面 | 音 |
| --- | --- | --- |
| 0 | バンッとタイマー（25:00と魔法陣）。上に「25分勉強すると、こうなる。」 | 低い F のピアノ和音＋鐘＋胴鳴り |
| 0〜5.2 | 刻みが少しずつ速まり、後半は目で追えない。陣が光を増し、画面が揺れる | オルゴールの「チッ・タッ」が昇りながら遠のき、下でふくらむ和音へ受け渡す |
| 5.2〜5.5 | 00:00「詠唱完了」で一瞬止まる | 高いオルゴールの一音 → 無音 |
| 5.5〜6.4 | 陣が弾け、流れ星が降りる | 鐘の和音、零れ落ちるオルゴール |
| 6.5〜8.6 | ボンッと「授かりし魔力 +25 MP」が数え上がり、すぐ上へ退く | 胴鳴りと低い F、曲が入る |
| 8.5〜16.1 | 流れ星が遺したもの: 星詠みの輝石が浮かび、解読文の書き出し | 低い鐘とオルゴール一音 |
| 16.1〜20.4 | 「何が降るかは、星しだい。」 | 鐘、遠くのフクロウ |
| 21.1〜27.6 | 「勉強記録アプリ マホログ」ロゴと入口の案内（予告編と同じ） | ピアノの和音 |
| 27〜28 | 淡いタイマーへ戻り、冒頭のバンッにつながる | 曲が闇へ溶ける |

```
25分勉強すると、ひとつの流れ星が降りてくる。

学んだ時間が魔力になる勉強記録アプリ『マホログ』
入口はプロフィールとコメント欄から

#勉強 #ポモドーロ #勉強アプリ #個人開発 #マホログ
```
