# TikTok 運用方針

## 役割
- **非日常への没入を見せる入口**。アプリの画面や操作はほぼ見せず、世界と体験だけで語る
- アプリへの誘導は、プロフィールのリンクとコメント欄に固定した URL から

## 投稿のきまり
- 縦長 1080×1920・30fps。アプリの部品から撮影ツール（`video/capture.mjs`）で作る
- **最初の3秒**に、いちばん目を引く動き（詠唱の魔法陣、流れ星など）を置く
- 文字は1節に5〜6秒。日本語は1秒に6〜8文字しか追えない
- 文字は画面の中ほどに置く（下端の説明文、右端のボタンに隠れないように）
- 最後のコマを最初のコマにつなげ、繰り返し再生で切れ目をなくす
- 音は曲（ピアノとオルゴール）＋効果音＋フクロウ。足音は入れない
- 頻度: **週2本（月・木の21時）**

## キャプションの型
```
（一行の詩的な導入）

学んだ時間が魔力になる勉強記録アプリ『マホログ』
入口はプロフィールとコメント欄から

#勉強 #勉強垢 #勉強アプリ #個人開発 #マホログ
```
タグは5つまで。内容に合わせて「#作業用BGM」「#ファンタジー」「#studywithme」と入れ替える。

## 見る数字
| いつ | 見るもの | 目安 |
| --- | --- | --- |
| 投稿の2日後 | 平均視聴時間、最後まで見た割合、最初の数秒で離れた割合 | 冒頭3秒で半分以上が残る |
| 毎週金曜 | プロフィールの表示数、リンクのタップ数（Vercel Analytics の utm_source=tiktok） | 週ごとに増えているか |
| 2週間ごと | `supabase/queries/engagement.sql` | 継続者・2週目に戻る人 |

- 平均視聴時間が短い → つかみを直す
- 最後まで見られているのに流入が少ない → 終幕の案内を直す
- 流入はあるのに続かない → アプリ側を直す

## 制作の流れ
1. この投稿案から作る動画を選び、Claude に「〇〇の動画を作って」と頼む
2. 静止画で構図を確かめ、全体を撮る（1本あたり30〜60分）
3. スマホで流して確かめ、時刻を指定して部分的に直す
4. `video/out/` の MP4 を投稿する
